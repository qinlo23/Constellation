# 新模块开发指南

项目要求 Java 25。业务模块位于 `backend/watermelon/<name>`，Java 包使用 `com.relax.owl.<name>`。

1. 创建普通 JAR 模块，parent 为 `com.relax:OWL:${revision}`，relativePath 为 `../../pom.xml`。
2. 在后端根 POM 的 modules 和 dependencyManagement 中登记模块。
3. 直接声明所用的 common-* 模块及 Web、Validation、MapStruct、AI 等第三方依赖。不要依赖已删除的 api，也不要新增聚合所有能力的 JAR。
4. 在 start 的 POM 中组装新业务。权限路径在 common-security 中配置，OpenAPI 分组在 common-web 中配置；start 仅承担启动、打包和必要的启动适配。
5. 实体、Mapper 归业务所有。跨业务访问通过所属业务的服务及 DTO，避免共享 Mapper。
6. `@OperationLog` 来自 `com.relax.owl.common.log.annotation`，只输出日志，没有 persist 参数或数据库写入。日志不要输出密码、Token 等业务敏感字段。
7. MyBatis 分页通过 `com.relax.owl.common.mybatis.MybatisPageConverter.toResultPage(page)` 转换。基础响应、异常与分页入参由 common-core 提供。
8. Lombok / MapStruct 注解处理器由根 POM 统一管理。代码生成器和 Velocity 使用 test scope。只有 start 开启 Spring Boot 可执行包打包。

公共模块的允许依赖和运行条件见 [公共模块架构](../spec/common-module-architecture.md)。

提交前执行：

```bash
python3 backend/scripts/check_module_boundaries.py
mvn -f backend/pom.xml verify
```
